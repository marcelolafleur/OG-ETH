# Universal Basic Income (UBI)

OG-Core can pay a universal basic income to households, set by the amounts per child, working-age adult and older person (`ubi_nom_017`, `ubi_nom_1864`, `ubi_nom_65p`), a cap (`ubi_nom_max`) and whether the amounts grow with the economy (`ubi_growthadj`); the theory is in the [OG-Core documentation](https://pslmodels.github.io/OG-Core/content/theory/government.html).  Ethiopia has no universal basic income, so the OG-ETH baseline sets all three amounts to zero.  A UBI reform sets them in birr per year.
